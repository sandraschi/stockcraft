# stockcraft MCP tools

Generated by `stockcraft tools --markdown`. Do not edit by hand: a test fails when this file
is out of date. Every tool is also a CLI verb (`stockcraft --help`). Dotted names (`app.verb`) are accepted.

| Tool | What it does | Required | Optional |
|---|---|---|---|
| `stock_status` | Inventory counts, valuation in cents, and low-stock count. | - | - |
| `stock_seed` | Seed demo inventory items if database is empty. | - | - |
| `stock_list` | List all SKUs with quantities, bins, and moving-average cost. | - | - |
| `stock_item_upsert` | Create or update an inventory SKU. | `sku`, `name` | `ean`, `ekr_account`, `location`, `min_stock`, `unit` |
| `stock_receive` | Wareneingang: receive stock and update moving-average unit cost. | `sku`, `qty`, `unit_cost_cents` | `reference` |
| `stock_issue` | Warenausgang: issue stock at current moving-average cost and emit bus events. | `sku`, `qty` | `reference` |
| `stock_transfer` | Umlagerung: move an item to a new bin location. | `sku`, `to_location` | `reference` |
| `stock_storno` | Reverse a movement with a linked Storno entry. | `movement_id` | `reason` |
| `stock_movements` | List recent immutable stock movements. | - | `limit` |
| `stock_low_alerts` | List items at or below Meldebestand (min_stock). | - | - |
| `stock_valuation` | Total stock valuation in integer cents. | - | - |
| `stock_inventur_start` | Start a new Inventur (stocktake) session. | - | `note` |
| `stock_inventur_count` | Record counted quantity for a SKU in an active stocktake. | `stocktake_id`, `sku`, `counted_qty` | - |
| `stock_inventur_commit` | Commit an Inventur session and post variance movements. | `stocktake_id` | - |
| `stock_pick_create` | Create a pick list (Kommissionierung) for one or more SKUs. | `reference`, `lines` | `source` |
| `stock_pick_list` | List open and committed pick lists. | - | - |
| `stock_pick_commit` | Commit a pick list and issue all picked SKUs from stock. | `pick_list_id` | - |
| `stock_export_csv` | Export current stock levels and valuation as CSV. | - | - |
| `stock_import_csv` | Import SKUs (and optional initial stock) from CSV text. | `csv` | - |
| `stock_inbox_drain` | Drain pending craft-biz bus events (invoice.issued, bom.exported) into pick lists. | - | - |
| `stock_lot_receive` | Receive stock into a tracked batch/lot with optional MHD expiry date (YYYY-MM-DD). | `sku`, `qty`, `unit_cost_cents`, `lot_no` | `expires_at`, `reference` |
| `stock_lots` | List tracked batches/lots in FEFO order (optional SKU filter). | - | `sku` |
| `stock_expiring_lots` | List active lots expiring within N days (MHD alert). | - | `within_days` |
| `stock_writedown` | Niederstwertprinzip: write down unit cost to a lower market value and emit adjustment. | `sku`, `new_cost_cents` | `reason` |
| `stock_reorder_plan` | Generate reorder suggestions for all SKUs at or below Meldebestand. | - | `emit_bus` |
| `stock_scan` | USB-HID barcode/EAN or SKU scan: lookup, receive, or issue by code. | `code` | `action`, `qty`, `reference`, `unit_cost_cents` |
